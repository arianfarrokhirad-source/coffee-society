# Architecture evolution

Temporary choices, recorded so "temporary" cannot become permanent by amnesia
(principle 14: no undocumented shortcuts).

**Adding a row is the price of taking a shortcut.** A row is deleted only when
the replacement has shipped — not when it is planned.

Migration cost: **S** ≤ half a commit · **M** ≈ one commit · **L** > one commit.
